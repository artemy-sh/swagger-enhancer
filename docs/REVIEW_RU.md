# Предрелизная проверка 2.1.0

Дата: 2026-11-04.

## Проверенный результат

- `npm test`: 117/117 проверок.
- `npm run test:browser`: 10/10 сценариев с установленным MV3-расширением, Swagger UI 4.19.1 и 5.33.0.
- Дополнительно установлено расширение из итогового ZIP 2.1.0: темы, авторизация в шапке, карточки и переходы схем, возврат наверх, девять переключателей и свой адрес работают без ошибок выполнения.
- Проверены обе темы, узкий экран, настоящий popup, синхронизация вкладок, мышь и клавиатура.
- Поиск и фильтр избранного проверены на больших виртуальных списках, включая операции вне экрана.
- Проверены авторизация с тестовыми данными, три действия копирования и подтверждения, статические и выполненные ответы, возврат наверх.
- Прямые ссылки раскрывают нужную схему. Карточки схем поддерживают связанные модели, Back, Escape и переход в Schemas.
- Адреса сохраняются тегами, стандартные правила можно удалить. Пустой список отключает панель, обычные страницы не изменяются.
- Настройки и избранное сохраняются при обновлении. Избранное разделено по спецификациям, старые значения остаются резервной копией.

## Пакет

`npm run package` проверяет согласованность версии в manifest, package.json, lock-файле и коде, длину описания и наличие рабочих файлов. Создаётся воспроизводимый ZIP с manifest.json в корне и SHA-256. Тесты, демо, зависимости, GIF и служебные скрипты исключены. Рабочие файлы и политика конфиденциальности включены.

Разрешение `scripting` используется для регистрации встроенных скриптов на пользовательских адресах. Доступ к сайтам не расширен. Аналитики, удалённого кода и отправки данных API разработчику нет.

## Известное ограничение

Swagger UI 5.33.0 может завершаться ошибкой при обновлении спецификации с удалением последней схемы. Сбой воспроизводится без расширения. Расширение не исправляет исходный Swagger UI или отсутствующие поля в спецификации API.
